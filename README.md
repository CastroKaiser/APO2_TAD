# Atividade AOP2 - Criação de um projeto com TAD implementado

Objetivo: Implementar um TAD para armazenamento dinâmico de números inteiros, utilizando uma lista encadeada

## Guia de Arquivos
- `lista.h` - Interface pública do TAD 
- `lista.c` - Implementação interna da lista encadeada
- `main.c` - Programa de exemplo de uso

## Operações 

As operações implementadas são todas as que foram definidas pelo professor, nenhuma função nova foi adicionada além das que já estavam definidas no escopo do projeto

## Como compilar

```bash
gcc lista.c main.c -o lista.exe
```

## Como rodar

```bash
./lista.exe
```
